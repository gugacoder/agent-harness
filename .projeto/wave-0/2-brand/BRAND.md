## Logomarca

- **logo** — Logomarca 1:1, somente o símbolo
- **logo+brand-horizontal** — Logomarca + texto na horizontal (logo à esquerda, texto à direita)
- **logo+brand-vertical** — Logomarca + texto na vertical (logo acima, texto abaixo)

## Fragmentos

- **brand** — Somente o texto do brand, para composições livres com ou sem a logo
- **brand+slogan** — Texto do brand + slogan abaixo, para composições livres com ou sem a logo

## Criativos

- **creative-horizontal** — Criativo horizontal para splashscreen
- **creative-vertical** — Criativo vertical para splashscreen

## Notas

- Nenhuma dessas imagens SVG possui margem. São feitas para se encaixarem nos espaços com margem e padding definidos externamente.
- Dentro dos SVGs, as partes imutáveis são agrupadas com o grupo `brand`. Ao transformar o SVG, o grupo `brand` deve ser levado as-is.
